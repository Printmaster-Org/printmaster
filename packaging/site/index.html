🖨️ PrintMaster Package Repository

Official package repositories for PrintMaster Agent.

Debian/Ubuntu (APT)

Quick Install (GPG signature verification enabled)

curl -fsSL https://packages.printmaster.work/install.sh | sudo bash

The installer verifies the signing-key fingerprint, configures APT with a dedicated keyring, and installs PrintMaster Agent.

Fedora/RHEL (DNF)

Quick Install (One-liner)

# Add repository and install
sudo dnf config-manager addrepo --from-repofile=https://packages.printmaster.work/printmaster.repo
sudo dnf install printmaster-agent

With GPG Verification (Recommended)

# Import GPG key first
sudo rpm --import https://packages.printmaster.work/gpg.key

# Add repository and install
sudo dnf config-manager addrepo --from-repofile=https://packages.printmaster.work/printmaster.repo
sudo dnf install printmaster-agent

After Installation

# Start the service
sudo systemctl start printmaster-agent
sudo systemctl enable printmaster-agent

Web UI: http://localhost:8080
